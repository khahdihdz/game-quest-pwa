# Questbound: Echoes of the Wild

Vietnamese-first hybrid adventure PWA made with vanilla HTML, CSS and JavaScript.

## Gameplay
- Explore multiple biomes, collect wood, stone and herbs.
- Turn-based combat, enemies, XP and leveling.
- Craft healing potions and a wooden sword.
- Upgrade your camp, complete quests and achievements.
- Local browser save and offline app-shell caching.

## Run locally
Run `python -m http.server 8080` and open `http://localhost:8080`. Service Workers require localhost or HTTPS.

## GitHub Pages
This repository includes a GitHub Actions workflow. In **Settings → Pages**, select **GitHub Actions** as the build source. Push to `main` to deploy. Expected URL: https://khahdihdz.github.io/game-quest-pwa/

## AI-assisted development
Use free tiers of cloud coding assistants (for example Gemini or GitHub Copilot where eligible) during development. Free quotas vary. The shipped game requires no AI API key and makes no external runtime AI calls.

## Privacy
Progress is stored locally in browser storage. No account, analytics or game backend is used.
